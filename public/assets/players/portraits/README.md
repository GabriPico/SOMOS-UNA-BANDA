# Retratos originales

Añadir aquí cada archivo definitivo, sin modificaciones gráficas.

Convención: `<player.id>.png` (por ejemplo, `1.png` para Arnau Casals).
Otros nombres o formatos se asocian en `src/data/playerPortraits.ts`.
No reemplazar `placeholder.svg` con el retrato de ningún jugador.

Guía completa y listado de IDs: `docs/PLAYER_PORTRAITS.md`.
