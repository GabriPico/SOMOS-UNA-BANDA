# Roadmap

## Hito 0 — Preparación

- Entorno instalado.
- Proyecto React y TypeScript creado.
- Git inicializado.
- Codex conectado.
- Documentación inicial creada.

## Hito 1 — Maqueta navegable

- Menú principal.
- Panel del club.
- Plantilla.
- Alineación.
- Partido.
- Resumen posterior.
- Clasificación.

Todos los datos serán inicialmente estáticos.

## Hito 2 — Una jornada jugable

- Selección de once.
- Simulación de partido.
- Resultado.
- Consecuencias.
- Clasificación.
- Guardado.

## Hito 3 — Temporada completa

- Calendario.
- 12 equipos.
- Jornadas.
- Playoff.
- Ascenso, fracaso y despido.
